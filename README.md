# StudyFlow 📚

StudyFlow is a browser-based student productivity web application designed to help students organize their daily study tasks and manage their study time efficiently.

## 🚀 Features

- Add and manage study tasks
- Track task completion progress
- Set task priorities
- Built-in Pomodoro study timer
- Personal notes section
- Dark mode
- Browser-based data storage
- Responsive design for desktop and mobile devices

## 🎯 Problem Solved

Students often struggle to organize study tasks, maintain focus, and track their daily progress.

StudyFlow provides a simple platform where students can manage tasks, use focused study sessions, write notes, and monitor their progress in one place.

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 📱 Responsive Design

StudyFlow is designed to work across desktop, tablet, and mobile devices.

## ⚡ How to Use

1. Open the StudyFlow website.
2. Add your study tasks.
3. Set task priorities.
4. Use the Pomodoro timer for focused study sessions.
5. Add notes when required.
6. Track your completed tasks using the progress section.
